# Money Empire

Jeu web de simulation financière / tycoon / idle game.

**Simulation fictive. Ceci n'est pas un conseil financier.**

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React
- localStorage (autosave 5s)
- Web Audio API (sons procéduraux)

## Fonctionnalités

- Capital animé, clics combo, revenus passifs, 20 business, 10 investissements
- Marché fictif (8 actifs), 40+ missions, 20 upgrades, 20+ événements
- Golden Rush, prestige, milestones, niveaux & XP
- **Managers**, **synergies**, **objectifs quotidiens**, **35 achievements**
- **Décisions stratégiques**, **réputation**, **tableau de statistiques**
- Mode compact mobile, particules, confetti, overlays premium
